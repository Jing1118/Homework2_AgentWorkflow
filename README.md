# 多Agent协作小红书种草文案生成工作流

> 本项目为《软件项目工程与项目实践》课程作业2：多Agent协作工作流系统实现

## 项目简介
本项目是一个基于多智能体（Agent）协作的内容创作工作流（Workflow）系统，完整模拟真实内容生产的「规划-写作-审校」全流程。通过自研的工作流编排引擎，实现多个Agent的流水线式协作，用户只需输入产品主题，即可自动生成符合小红书风格的高质量种草文案。

项目不仅提供命令行（CLI）运行方式，还内置了基于 Streamlit 的**可视化 Web 交互界面**。同时，在基础顺序执行之上，引擎内置了**字数检测与循环重写**的高级流程控制机制。

## 功能特性

### 核心功能
- ✅ **多Agent流水线协作**：规划Agent、写作Agent、审校Agent三个核心节点顺序执行，端到端完成内容生产
- ✅ **顺序化工作流编排**：内置工作流引擎，支持灵活配置执行节点与执行顺序
- ✅ **全链路状态共享**：基于全局上下文实现Agent间消息传递与状态同步
- ✅ **基本流程控制**：支持标准顺序执行模式，节点间数据传递链路清晰

### 扩展功能
- ✅ **高级流程控制（条件循环）**：内置“字数检测”机制。写作完成后自动检测字数，若不达标（<300字）则触发条件循环，强制打回写作Agent重写（最高2次）
- ✅ **可视化Web编排界面**：基于 Streamlit 构建交互式界面，一键触发工作流，实时展示最终文案与底层执行日志
- ✅ **错误重试与容错机制**：单节点执行失败自动重试，异常场景优雅终止，避免流程直接崩溃
- ✅ **执行日志持久化**：完整记录全流程带时间戳的执行日志，支持本地文件保存，可追溯执行细节
- ✅ **高可扩展架构**：基于面向对象基类设计，新增Agent无需修改核心引擎代码
- ✅ **全流程状态追踪**：记录单步耗时、总耗时、执行状态、重写次数等多维度信息

## 环境要求
- 编程语言：Python 3.10 及以上版本
- 依赖库：
  - `requests`：用于调用大语言模型API
  - `python-dotenv`：用于安全管理环境变量与API密钥
  - `streamlit`：用于构建可视化 Web 界面

## 快速开始

### 1. 安装依赖
在项目根目录打开终端，执行以下命令安装依赖：
```bash
pip install -r requirements.txt
```

### 2. 配置 API 密钥
1. 在项目根目录找到 `.env.example` 文件。
2. 将其复制一份，并重命名为 `.env`。
3. 打开 `.env` 文件，将 `DEEPSEEK_API_KEY` 的值替换为你的真实 DeepSeek API 密钥：
```env
DEEPSEEK_API_KEY=你的真实API密钥
```
*(注：请勿将包含真实密钥的 `.env` 文件上传至公开仓库)*

### 3. 运行项目
本项目提供两种运行模式，任选其一：

**模式一：可视化 Web 界面（推荐）**
```bash
streamlit run app.py
```
运行后浏览器会自动弹出一个交互式网页，输入主题点击生成，即可实时查看文案与日志。

**模式二：命令行终端**
```bash
python main.py
```
运行后会在控制台输出执行过程、最终文案与完整日志，同时自动在 `logs` 文件夹生成日志文件。

### 4. 自定义输入
- **Web 界面**：直接在网页输入框中修改主题即可。
- **命令行**：打开 `main.py`，修改 `user_input` 中的 `user_topic` 字段。

## 扩展使用：新增Agent节点
本架构支持灵活扩展，以标题优化Agent为例，仅需两步即可接入工作流，无需修改引擎核心代码：
1. 导入对应Agent：
```python
from workflow.agents.title_optimizer_agent import TitleOptimizerAgent
```
2. 在执行列表中插入节点，调整执行顺序：
```python
agent_list = [
    PlannerAgent(),
    WriterAgent(),
    TitleOptimizerAgent(),
    ReviewerAgent()
]
```
运行后即可自动执行标题优化步骤，充分验证架构的可扩展性。
